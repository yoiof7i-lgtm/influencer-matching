# 협찬ON 평가 점수제 확정안 (v2)

## 1. 평가 흐름
1. 매칭 수락 → 인플 방문 → 촬영
2. 인플: "촬영이 끝났습니다" 버튼
3. 사장님: "수고하셨습니다~ 후기 잘부탁합니다~" 버튼
4. 인플: 조건에 맞는 포스팅 제출 (링크)
   - 조건 충족 → +점수 획득
   - 조건 미충족 → 0점 또는 -점수
5. 양방향 체크리스트 평가 제출
6. 2주 모아 일괄·익명 반영

## 2. 평가 항목 체크리스트 10가지 (각 항목당 5단계)

### 인플루언서 → 사장님 평가 (10항목)
| # | 항목 | 기준 |
|---|---|---|
| 1 | 맛 (음식/음료 맛) | 음식의 맛과 품질 |
| 2 | 친절 (직원 응대) | 직원의 친절도와 서비스 태도 |
| 3 | 인테리어/분위기 | 실내외 디자인, 사진 찍기 좋은 공간 |
| 4 | 청결 (위생) | 화장실, 테이블, 주방 위생 상태 |
| 5 | 접근성 (위치/주차) | 찾기 쉬운 위치, 주차 편의 |
| 6 | 가성비 | 가격 대비 만족도 |
| 7 | 사진 스팟 | 인스타 촬영하기 좋은 포인트 제공 |
| 8 | 협찬 조건 준수 | 약속한 메뉴/서비스 제공 여부 |
| 9 | 대기/속도 | 주문~서빙 시간, 대기 관리 |
| 10 | 재방문 의사 | 다시 가고 싶은 정도 |

### 사장님 → 인플루언서 평가 (10항목)
| # | 항목 | 기준 |
|---|---|---|
| 1 | 예약/일정 준수 | 약속 시간, 일정 이행 |
| 2 | 촬영 태도 | 매너, 과도한 요구 없음 |
| 3 | 사진 퀄리티 | 게시물 사진 완성도 |
| 4 | 글 정성 (캡션) | 광고 문구 자연스러움, 가게 정보 정확성 |
| 5 | 협찬 조건 이행 | 약속한 게시물 수/기간 준수 |
| 6 | 태그/위치 정확성 | 위치 태그, 해시태그, 계정 태그 정확성 |
| 7 | 팔로워 반응 | 게시물에 대한 팔로워 관심/질문 |
| 8 | 소통 태도 | 요청 사항 대응, 커뮤니케이션 |
| 9 | 게시물 노출 성과 | 조회수/도달 성과 |
| 10 | 재협찬 의사 | 다시 협찬하고 싶은 정도 |

## 3. 항목당 점수 (5단계)
| 선택 | 인플 점수 반영 (10점 만점) | 업소 점수 반영 (100점 만점) |
|---|---|---|
| 매우 좋음 | +0.2 | +2.0 |
| 좋음 | +0.1 | +1.0 |
| 보통 | 0 | 0 |
| 아쉬움 | -0.1 | -1.0 |
| 아쉬움이 큼 | -0.2 | -2.0 |

※ 10항목 전부 평가 → 누적 범위: -20.0 ~ +20.0 (10점 만점 기준)

## 4. 점수 표시 방식
- 기본 시작점: 인플 5.0 / 업소 50.0 (신규 계정)
- 최초 계산: 시작점 + (합산 평가 × 가중치) → 0~10 / 0~100 범위로 정규화
- 예시: 인플 10점 만점에 7.1 / 업소 100점 만점에 71.1
- 소수점 1자리까지 표시

## 5. 포스팅 조건 점수 (인플 획득)
사장님이 초대 시 약속한 조건 기준:
| 상황 | 인플 점수 |
|---|---|
| 조건 충족 포스팅 (기간 내 제출) | +0.2 |
| 늦게 제출 (기간 초과) | +0.1 |
| 미제출 | 0 |
| 조건 위반 (미승인 내용) | -0.1 |
| 후기 링크 3회 미제출 | 협찬OFF 자동 전환 |

## 6. 반영 방식
- 2주 단위 모아서 일괄 반영
- 익명 처리 (평가자 정보 비노출)
- 3주 재방문 금지 규칙과 연동

## 7. 자동화 로드맵
- MVP: 관리자 화면에서 양방향 체크리스트 수동 입력
- 다음: 인플/사장 앱에서 직접 평가 UI
- Meta API 연결 후: 포스팅 자동 감지 → 조건 충족 자동 판정
