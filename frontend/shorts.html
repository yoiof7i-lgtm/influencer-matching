🛍 쇼핑쇼츠 기획 메이커

상품 상세페이지 스크린샷을 올리면 분석 · 대본 3안 · 촬영안 · AI 영상 프롬프트 · 제목/태그를 한 번에 만들어요. (쿠팡·네이버·무신사·올리브영·알리 등 어떤 쇼핑몰이든 OK)

📖 사용 방법 (클릭해서 펼치기)

▼
전체 흐름 (쇼츠 완성까지 약 10분)
STEP 1 쇼핑몰 상품 상세페이지를 스크린샷 1~3장으로 저장 (상품명·가격·옵션이 보이게)
STEP 2 이 페이지에 업로드 → 타겟 연령·대본 구조 선택 → [✨ 쇼츠 패키지 만들기]
STEP 3 생성 결과 확인:
  · 🔍 상품 분석 — 특징/장단점/타겟 확인
  · 🎬 대본 3안 — 마음에 드는 안 → [🎙 TTS 열기] 버튼 클릭 → TTS 사이트(타입캐스트 등)에 대본 붙여넣기 → 음성(mp3) 다운로드
  · 🖼 사진·영상 프롬프트 — 아래 구글 플로우 사용
  · ✏️ 제목·태그 — 게시물 업로드 때 사용
STEP 4 🖼 구글 플로우로 이동 버튼 클릭 →
  ① "사진 프롬프트 전체 복사" 버튼 누르고, 플로우에서 이미지 생성에 붙여넣기 (상품 스크린샷도 함께 첨부)
  ② 생성된 이미지 저장
  ③ "영상 프롬프트 전체 복사" 버튼 누르고, 플로우에서 비디오 생성(Veo)에 붙여넣기 → 저장된 이미지로 영상 생성
STEP 5 만든 영상 클립들 + TTS 음성 → 캡췬/인스타 릴스에서 합치기 → 제목·태그 붙여서 업로드!

💡 팁: 대본 3안 중 1안만 골라 진행해도 되고, 사진 프롬프트는 상품 스크린샷과 함께 넣어야 상품이 정확히 나와요.

📸 클릭해서 사진 선택 (최대 7장) — 쇼핑: 상품 스크린샷 / 호텔: 객실·시설 사진

키는 이 브라우저(localStorage)에만 저장되고 Google API로만 전송돼요.
